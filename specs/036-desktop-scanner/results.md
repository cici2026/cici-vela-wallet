# 036 · Desktop Scanner — results

分支 `036-desktop-scanner`,叠在 035 上。

## Phase 1 — 不用相机的那一半(而且三个桌面都能用)

DS1 从 spec 021 起就是一张画:取景框、一句提示、两个工具按钮,**背后什么都没有**。
这一刀接的是**从图片里读码**——截图、别人发来的照片、这只钱包自己存出去的分享卡。

三块:

1. **解码**(`executor/qr.rs`,`rqrr`,纯 Rust —— 不要 zbar、不要 C 工具链,
   **这条路不能成为某个平台编不过的理由**)。答的是"图里有什么字",
   **它不判断任何事**。
2. **`ethereum:` 分词**(`flows/eip681.rs`,照 web 的 `eip681.ts` 移植),
   **两条用真 bug 换来的拒绝原样保留**:
   - `/transfer` 里的 `value` **不是**代币金额(它是随调用附带的以太),
     照它读会把"附带 1 ETH"变成一笔锁定的 10¹² USDC;
   - **任何别的函数都不是付款**(`approve` 曾经掉进原生分支,把**代币合约**
     当成收款人 —— 一次伪装成付款的销毁)。
3. **路由**(照 web 写好的那份):发送流程里由**核心**裁决(`ScanResolved`);
   从首页扫则**开一个新的发送**,预填,并且**恰好在请求指明链的时候锁定**。

### 顺手抓到一个真 bug

扫码弹层的卡片**在遮罩里面**,而遮罩自己带着"点一下就关"。所以点卡片上的任何东西
——包括它的工具按钮——都会冒泡到遮罩的关闭:**工具触发了,然后它打开的屏幕在它背后被清掉。**
第一次实机就撞上了(扫描成功、发送打开、随即被关)。这只壳里其他覆盖层早就都拦了这一下;
这一个是在**还没有东西可点的时候**画的,所以从来没人发现。

### 一个新的 env 钉

`VELA_SCAN_FILE=<路径>` 跳过文件对话框 —— 和 `VELA_GALLERY_TAB` / `VELA_FLOW` 同一族,
理由也一样:**文件对话框是系统窗口,这个 app 驱动不了它**,没有这个钉,
任何截图流程和无头运行都永远到不了扫码的另一侧。
